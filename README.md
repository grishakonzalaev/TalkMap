# TalkMap — тактильно-озвучиваемая карта для незрячих

Android-приложение, которое позволяет незрячему пользователю исследовать
карту OpenStreetMap **ощупыванием**: скринридер (TalkBack) озвучивает
объект, находящийся под пальцем, и сопровождает это короткой вибрацией.

## Как это работает

1. **Текущее местоположение.** При первом запуске приложение запрашивает
   доступ к геолокации и открывает карту в том месте, где находится
   пользователь (если разрешения нет или GPS недоступен — показывается
   Новосибирск).
2. **Тайлы карты OpenStreetMap.** Карта рисуется библиотекой
   [osmdroid](https://github.com/osmdroid/osmdroid) с бесплатными тайлами
   OSM (сервер MAPNIK).
3. **Объекты рядом.** Вокруг центра экрана приложение опрашивает
   [Overpass API](https://overpass-api.de/) и получает подписанные объекты
   (улицы, дома, магазины, остановки, парки и т. д.). При перетаскивании
   карты объекты перезагружаются.
4. **Ощупывание.** Каждый объект становится **виртуальным узлом
   доступности** (`AccessibilityNodeProvider`). Когда пользователь ведёт
   палец по экрану, TalkBack видит виртуальный узел под пальцем и
   произносит: «Красный проспект, проспект», «Гостиница, гостиница» и т. п.
   При смене объекта подаётся тактильный сигнал (вибрация).
## Требования

- Android **5.0 (API 21)** или новее.
- Установленный **TalkBack** (или другой скринридер) — включён в настройках
  `Настройки → Специальные возможности`.

## Установка (APK)

Готовый отладочный APK лежит здесь:

```
app/build/outputs/apk/debug/app-debug.apk
```

Установите его на телефон удобным способом (кабель + `adb install`, либо
копирование файла и «Установить из неизвестных источников»):

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## Сборка из исходников

Нужны JDK 17+ и Android SDK (platform 34, build-tools 34). Сборка:

```powershell
.\gradlew.bat assembleDebug
```

## Что видит пользователь

- **Один палец** — ведение по карте; под пальцем озвучивается ближайший
  объект в радиусе касания.
- **Два пальца** — изменение масштаба (стандартный жест osmdroid).
- **Свайп влево / вправо** — перемещение фокуса от объекта к объекту.
- **Свайп вверх / вниз** — сдвиг карты (север / юг).

Внизу (в верхней части экрана) показывается текстовый статус: поиск
местоположения, загрузка объектов, количество найденных объектов, ошибка
сети.

## Архитектура проекта

```
app/src/main/java/ru/talkmap/app/
├── App.java                  — настройка osmdroid (кэш, User-Agent)
├── MainActivity.java         — запрос геолокации, статусные сообщения
├── AccessibleMapView.java    — карта + виртуальные узлы TalkBack (ядро)
├── OsmApiClient.java         — запрос объектов из Overpass API
├── MapFeature.java           — объект карты (координаты, имя, тип)
├── CategoryNames.java        — словарь «тип OSM → русское название»
└── RuSpeech.java             — подготовка фраз для озвучки
```

## Ограничения

- Карта использует онлайн-тайлы OSM и Overpass API: для работы нужен
  интернет. Валидный User-Agent зафиксирован, но при большом количестве
  пользователей стоит использовать собственный Overpass-сервер и кэш.
- На более детальном зуме список объектов ограничен (1500 за запрос).

## Проверено

- Проект собирается командой `.\gradlew.bat assembleDebug` (Gradle 8.7,
  AGP 8.5.2, compileSdk/targetSdk 34) — **BUILD SUCCESSFUL**.

  лаунчер-активность `ru.talkmap.app.MainActivity`.

  тайлов требуют живого телефона.
